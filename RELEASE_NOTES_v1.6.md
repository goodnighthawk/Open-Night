# Open Night v1.6

Generated-vehicle polish and traffic handling release.

- Tightened all 28 generated PNG crops around the vehicle artwork while retaining transparent edge padding.
- Increased generated-vehicle display length by 15% so the new fleet reads at the intended scale.
- Removed the duplicate legacy ellipse shadow from generated vehicles, which could resemble a clipped overlapping car.
- Added class-aware steering limits so buses, tankers, trucks, and other traffic turn progressively instead of snap-spinning.
- Doubled job NPC locations from 20 to 40, providing 20 supplier/buyer pairs.
- Preserved the recently added player pixel-car sheets alongside the generated fleet.

Wire protocol and public release version: `1.6`.
