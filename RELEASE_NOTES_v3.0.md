# Open Night v3.0

HUD 3.0 promotes the approved neon character, equipment, inventory, and combat shell into the canonical Open Night client.

- Keeps the live top-down player centered and visible beneath both the open and closed HUD states.
- Replaces the legacy inventory screen with one Escape-open layout containing top navigation, compact character stats, 20 square equipment and pocket sockets, 10 ring sockets, and an empty 60-cell inventory grid.
- Provides the 13-key combat hotbar in the exact `` ` 1 2 3 4 5 6 7 8 9 0 - = `` order while keeping the hotbar and core resources visible during play.
- Adds six heart units, three armor units, energy, and side-profile-brain fatigue indicators without enclosing resource boxes.
- Adds the large 10-round magazine display, hold-R reload progress, and individual-round drag/top-up interaction shell.
- Moves the authoritative square GridWorld minimap to the lower-right corner, places active chat in the bottom gap between the hotbar and minimap, and reserves a non-overlapping center opening for play.
- Restores access to Resume, Options, Radio Stations, Controls, Friends, Messages, and Quit from the Escape-open navigation strip.
- Preserves the existing server inventory authority; the new 60-cell grid and equipment system intentionally ship as an empty presentation shell for later item integration.

Release verification covers the canonical launcher path, open and closed HUD rendering, centered-player visibility, navigation routing, exact slot counts, aligned inventory cells, hotbar input, magazine reload interactions, resource separation, fatigue art, minimap placement, and all carried main-release audits.
