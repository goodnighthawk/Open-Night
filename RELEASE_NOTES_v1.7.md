# Open Night v1.7

Live regional and in-car radio release.

- Added a ten-slot car-radio selector, initially populated with OOC Radio, Hive365, and Radio Free Zion.
- Added map-region station rotation so different server regions receive different radio programming on foot.
- Added fail-soft desktop live-stream playback through VLC; the game and ordinary sound effects remain usable if VLC is unavailable.
- Added a prominent music-note toggle in the pause menu. A diagonal slash clearly indicates that radio/music is muted.
- Added a smaller independent speaker toggle for game audio, including engines, footsteps, collisions, horns, and UI sounds.
- Kept music and game-audio mute states fully independent.

Wire protocol and public release version: `1.7`.
